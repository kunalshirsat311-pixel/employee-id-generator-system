# Employee ID Generator System

A beginner Python project that simulates an employee registration system used in HR operations.

The system:
- collects employee details
- generates unique employee IDs
- creates company email IDs
- stores employee records permanently using file handling

## Features

- Dynamic Employee ID Generation
- Department Code Extraction
- Automated Email Creation
- File Storage System
- Formatted Employee ID Card
- Persistent Employee Records

## Technologies Used

- Python
- Functions
- File Handling
- Random Module
- String Manipulation

## Future Improvements

- GUI Interface

- Search Employee Feature
- Employee Record Viewer
- Admin Dashboard

## How to Run

Run the program using:
